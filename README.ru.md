# Extended Toolbar

[English](README.md) | [Русский](README.ru.md)

Модульный и настраиваемый тулбар для osu!cc и osu!lazer.

## ✨ Возможности

- **Модульные зоны (Лево, Центр, Право)**: Свободное распределение любых элементов тулбара по трём зонам.
- **Режим редактирования (Edit Mode)**: Перетаскивание блоков мышью (Drag & Drop) в реальном времени.
- **Плавающий остров (Floating Island / Dock)**: Превращение стандартного тулбара в парящий остров с настройкой скругления углов, ширины (длины), оффсетов по X и Y.
- **Визуальные стили и эстетика**:
  - Настройка высоты тулбара и прозрачности фона.
  - Регулировка плотности элементов (Spacing).
  - Верхнее фоновое затемнение экрана (Glow / Виньетка) позади тулбара.
  - Адаптация и скругление углов панелей меню выбора карт (SongSelect).
  - Разделители (пустой отступ, тонкая линия, точка).
- **Кастомизация кнопки профиля**:
  - Смена порядка аватара и никнейма (аватар слева, только аватар, только ник и др.).
  - Выбор расположения ранга и PP (справа или слева).
- **Пресеты и экспорт**:
  - Сохранение именованных пресетов в формате JSON.
  - Быстрый экспорт и импорт раскладок через компактный код в буфере обмена.
- **Умное позиционирование оверлеев**: Автоматическая привязка всплывающих окон логина и музыкального плеера под перемещённые кнопки.

## 📦 Установка

1. Скачайте `ExtendedToolbar.dll` из последнего релиза.
2. Поместите файл в папку `%APPDATA%\osu\osu-cc\plugins\extended-toolbar\`.
3. Запустите игру и настройте тулбар в Настройках или через контекстное меню (ПКМ по тулбару).

## 🛠️ Сборка

```bash
dotnet build -c Release
```
